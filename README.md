# 小红书起号五步 SOP｜课程讲义演示站

静态课程讲义站点，按顺序演示小红书冷启动五步，并附可填写工作表：

**定位 → 对标 → 矩阵获客 → 矩阵基建 → 引流**

适合直播课 / 投屏演示：大标题、步骤进度、上一页/下一页、讲者提示开关、大字模式，表格填写保存在本机浏览器。

## 在线打开

- GitHub Pages：见仓库 Settings → Pages，或 README 发布后给出的 Pages 地址
- 本地：直接打开 `index.html`，或：

```bash
python3 -m http.server 8765
# 浏览器访问 http://127.0.0.1:8765
```

填写内容保存在浏览器 `localStorage`；顶栏可「导出」JSON、「清空」或打印。

## 直播快捷键

| 按键 | 作用 |
|------|------|
| `→` / `N` / `PageDown` | 下一步 |
| `←` / `P` / `PageUp` | 上一步 |
| `T` | 开关讲者提示 |
| `L` | 开关大字模式 |

右下角也有「上一步 / 下一步」浮动条。

## 五步模块

1. **定位** — 最小可行定位、三张清单、定位句、12 选题树、发布前检查、7 天闭环
2. **对标** — 定位小卡、四入口找号、六项拆解、对标账号表
3. **矩阵获客** — 角色公式、四类内容、三层标签、主页转化检查
4. **矩阵基建** — 分工表、内容任务卡、异常记录、扩号门槛
5. **引流** — 站内承接自检、私信送达测试、7 天引流测试表

## 文件

| 文件 | 说明 |
|------|------|
| `index.html` | 页面结构与五步讲义内容 |
