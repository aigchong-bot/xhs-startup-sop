# 小红书起号五步 SOP 导览站

结构化整理自 [@JessiCao_JC](https://x.com/JessiCao_JC) 在 X 上的小红书起号系列，按顺序串成一条可浏览、可填写的静态站点：

**定位 → 对标 → 矩阵获客 → 矩阵基建 → 引流**

本仓库是**合集导览与可填工作表**，不是原文转载。细节与模板请以原作者帖子为准。

## 在线打开

本仓库为纯静态页，可直接打开 `index.html`，或用任意静态托管（GitHub Pages、Netlify、本地 `python -m http.server`）。

```bash
# 本地预览
python3 -m http.server 8765
# 浏览器访问 http://127.0.0.1:8765
```

填写内容保存在浏览器 `localStorage`；顶栏可「导出」JSON、「清空」或打印。
